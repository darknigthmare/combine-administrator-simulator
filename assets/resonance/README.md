# Candidats graphiques de Half Life Resonance

Le dépôt contient **27 PNG vérifiés**, dont **8 nouveaux fichiers pour 7 cibles** dans le lot D du 20 novembre : trois poses de personnages de réserve, deux poses de boss, deux maîtres de décor et un sol séparé. Un maître et son sol représentent un seul stage en cours. Les fichiers sont rangés par lot sous `candidates/` et aucun n’est certifié 1:1.

Les six fichiers initiaux sont conservés. Deux panoramas initiaux sont utilisés par le prototype Boss Battle. Les nouveaux personnages, créatures et véhicules sont des poses statiques candidates, sans intégration runtime. Aucun clip animé ni stage à six couches n’est déclaré terminé. Les quatre fichiers de couches représentent trois IDs de plan identifiés ; le fichier historique de Cité 17 reste sans ID car il mélange le ciel et la Citadelle.

Le journal courant contient 39 demandes : 27 PNG présents et 12 refus sans sortie. Le lot D comprend le refus d’une correction de détourage du Strider ; la première version produite est conservée avec ses limites. Les deux versions de Rocket Turret du lot C représentent toujours une seule machine. Aucune révision refusée n’est comptée comme fichier.

Les images sont conservées sans rééchantillonnage ni remplacement silencieux. Les variantes éditées ont leur provenance; les essais non sélectionnés ne gonflent pas le nombre de sujets disponibles. Les PNG avec alpha conservent leur canal original. Les faibles franges et la fidélité aux modèles doivent être validées avant utilisation en jeu.
