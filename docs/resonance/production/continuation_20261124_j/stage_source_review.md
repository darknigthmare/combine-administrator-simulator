# Lot J — références et revue des décors

Date : 24 novembre 2026.

Dix cibles reçoivent un master candidat, soit onze PNG avec la correction du barrage. Toutes les captures ci-dessous ont été inspectées avant génération. Les sources proviennent des jeux publiés indiqués dans le registre, via leurs fiches de capture Combine OverWiki. Les points de vue sont adaptés latéralement pour une arène 2D ; aucune conformité 1:1 n’est certifiée.

Tous les résultats sont des panoramas RGB opaques 1672 × 941. Aucun personnage, HUD ou étiquette visible n’a été relevé pendant la revue. Les octets des PNG sont ceux retournés par image_gen, sans recomposition procédurale ni modification de pixels après génération. Les SHA256 ont été vérifiés une nouvelle fois lors de la restauration locale.

## Travail restant

La variante incinérateur de la Salle 17 demeure absente : ce lot apporte seulement la chambre des récepteurs. Tous les masters nécessitent une comparaison source plus fine, une calibration avec les combattants et la production des couches de décor si le moteur l’exige. Aucun de ces nouveaux masters n’est branché au runtime ; aucun lot de six couches ni animation de stage n’est déclaré terminé.
