## Contrôle alpha

Chaque image a été inspectée, puis revue sur des compositions avec fond blanc et fond noir. Les larges lueurs de certains aperçus bruts ne sont pas visibles au compositing avec le canal alpha. Les fichiers PNG originaux sont conservés tels quels. La version recadrée d’Uriah a été contrôlée séparément.

Les pieds, l’échelle commune, les pivots, l’orientation et les clips d’animation restent à préparer pour le moteur. Les détails fins des visages, armes et costumes demandent encore comparaison aux modèles originaux.

## Reprise après interruption d’environnement

Les 13 réponses imagegen et leurs prompts conservés ont permis de retransférer les PNG sans régénération. Le SHA Git de chaque blob a été calculé depuis les octets et comparé au retour GitHub. Les PNG récupérés localement ont également retrouvé les SHA-256 calculés avant l’interruption. Le registre documente cette récupération; aucun compteur alpha inaccessible n’a été inventé.
