## Portée de la fidélité

Chaque image est un candidat fondé sur une capture, un modèle, une illustration officielle ou un effet du jeu, avec version et source indiquées dans les registres partiels. Les visuels détaillés générés traduisent les modèles originaux et ne constituent pas des extractions des jeux. **Aucune image n’est déclarée certifiée 1:1.** Les différences de pose, de proportions, de texture et les détails non montrés restent à examiner.

Une pose isolée ne termine ni un personnage ni ses animations. Un état de projectile ne termine pas sa boucle, ses impacts ou ses transitions. Un master de stage ne constitue pas un stage complet à six plans; la géométrie est adaptée au combat en vue latérale. Les décors de ce lot sont indépendants des personnages et boss.

Les fichiers restent candidats hors runtime. Le compteur historique de deux arrière-plans intégrés au prototype n’est pas une intégration de ce nouveau lot. Aucune entrée d’archive ne devient automatiquement du contenu publié.

## Vérifications

Les validateurs contrôlent les identifiants, associations, dimensions, signatures PNG et SHA-256; les inspections visuelles sont consignées dans les registres. La transparence est évaluée sur une vraie composition alpha; un aperçu brut peut afficher des couleurs sous des pixels totalement transparents. Le seul avertissement historique connu concerne une ancienne couche de Cité 17 sans identifiant de plan.

Commandes de vérification :

```sh
node scripts/validate-resonance-design.mjs
node scripts/validate-resonance-boss-design.mjs
node scripts/audit-resonance-production.mjs --write-report
node scripts/sync-resonance-production.mjs --write
git diff --check
```
